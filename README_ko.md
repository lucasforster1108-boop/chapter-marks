# chapter-marks

긴 영상에 챕터가 없으면 진행 바를 드래그하는 건 매번 도박입니다. "그 장면" 찾으려고 앞뒤로 왔다 갔다 하는 데 질려서 만들었습니다. 영상을 대신 훑어보고, 장면이 실제로 바뀌는 지점에 챕터를 찍어줍니다.

## 뭘 하는 도구인가

챕터 경계는 두 가지 신호에서 찾습니다.

1. **장면 전환** — ffmpeg의 장면 감지(`select='gt(scene,…)'`)를 씁니다. 화면이 완전히 다른 내용으로 하드 컷되면 거기가 경계입니다. 어떤 영상이든 됩니다.
2. **funscript의 긴 공백** (선택) — 영상 옆에 같은 이름의 `.funscript`가 있으면, 스크립트 움직임이 거의 없는 구간이 오래 이어질 때(기본 45초 이상)도 경계로 셉니다. 카메라로는 안 보이는 단락의 끊김을 잡기 위한 장치입니다.

둘을 합친 뒤 `--min-length`보다 짧은 챕터는 앞 챕터에 접어 넣습니다. 첫 챕터는 항상 0초에서 시작합니다.

결과물은 세 가지입니다.

- `<name>.ffmeta` — FFMETADATA 형식 챕터 파일. mkv/mp4에 그대로 remux할 수 있습니다
- `<name>.chapters.json` — 챕터별 `title` + `start_time`. Stash 같은 도구가 가져가는 형태입니다
- 콘솔에 찍히는 목록. 각 줄에 `[scene]` 또는 `[gap]` 태그가 붙어서 경계가 어디서 왔는지 알 수 있습니다

`--embed`를 붙이면 챕터가 박힌 `<name>_chapters.mkv`도 만듭니다. 스트림 복사로 재인코딩이 없고, 원본 파일은 건드리지 않습니다.

## 설치

Python 3.10+, 그리고 PATH에 잡힌 `ffmpeg`와 `ffprobe`. 그게 답니다. 스크립트는 표준 라이브러리만 써서 pip로 깔 게 없습니다(`requirements.txt`는 바로 그 말을 적어두려고 있는 파일입니다).

## 사용법

```bash
# 기본: 장면 전환만으로
python chapters.py movie.mp4

# 같은 이름의 movie.funscript가 있으면 자동으로 씁니다.
# 직접 지정도 됩니다
python chapters.py movie.mp4 --script movie.funscript

# 감지를 예민하게, 챕터 최소 길이 30초,
# 새 mkv에 챕터까지 박아서
python chapters.py movie.mp4 --scene-threshold 0.3 --min-length 30 --embed
```

출력은 대략 이렇습니다.

```
movie.mp4: 4 chapters (2 scene cuts, 1 gap breaks)
   1. 00:00:00  Chapter 1  [start]
   2. 00:00:20  Chapter 2  [gap]
   3. 00:00:30  Chapter 3  [scene]
   4. 00:01:00  Chapter 4  [scene]
```

## 파라미터

| 플래그 | 기본값 | 역할 |
|---|---|---|
| `--script` | 같은 이름의 `.funscript`(있으면) | 공백 감지에 쓸 funscript |
| `--scene-threshold` | `0.4` | 컷으로 판정할 장면 score 문턱. 낮을수록 예민 |
| `--min-length` | `60` | 챕터 최소 길이(초). 이보다 짧으면 앞 챕터에 합침 |
| `--gap` | `45` | 스크립트 저활동이 몇 초 이어지면 경계로 볼지 |
| `-o`, `--out-prefix` | 확장자를 뺀 영상 경로 | `.ffmeta` / `.chapters.json` 출력 위치 |
| `--embed` | 꺼짐 | 챕터가 박힌 `<name>_chapters.mkv`도 remux |

## 솔직한 한계

- **페이드와 디졸브는 못 잡습니다.** 장면 감지는 급격한 변화를 보는 방식이라 느린 크로스페이드는 문턱 아래로 그냥 지나갑니다. 사실상 하드 컷 전용입니다.
- **문턱값은 영상마다 손봐야 합니다.** 화려한 몽타주는 0.4에서도 계속 걸리고, 고정 카메라 토크 영상은 한 번도 안 걸릴 수 있습니다. 돌려보고, 목록 보고, 조정하고, 다시 돌리세요. 빠르니까요.
- **gap 모드는 스크립트 품질이 전부입니다.** 원래 성기고 자연스러운 쉼이 많은 스크립트는 없는 경계를 만들어내고, 처음부터 끝까지 빽빽한 스크립트에서는 공백이 안 나옵니다. 출력의 `[gap]` 태그는 직접 판단하시라고 붙여둔 겁니다.
- 챕터 이름은 `Chapter N`이 답니다. 이름 붙이는 건 여러분 몫입니다. 이 도구는 이음매만 찾지 내용을 이해하지는 않습니다.

## 테스트

`tests/run_tests.py`는 생김새가 완전히 다른 구간 세 개를 하드 컷으로 이어 붙인 90초짜리 합성 영상(컷 지점은 정확히 30초와 60초)과, 20초부터 55초간 완전히 비어 있는 funscript를 만들어서, 박아 넣은 챕터를 ffprobe로 다시 읽어오는 것까지 전체 과정을 검증합니다. 제 환경에서는 검출된 챕터가 0 / 20 / 30 / 60초로 정확히 맞았습니다. 테스트 어디에도 실제 영상은 쓰지 않았습니다.
