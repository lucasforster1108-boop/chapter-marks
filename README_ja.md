# chapter-marks

## まず、普通の言葉で言うと

長いアダルト動画には、たいていチャプターが付いていません。途中のあの場面に飛びたいと思っても、シークバーをドラッグして当てるしかなくて、行き過ぎたり足りなかったり、毎回うろうろすることになります。

このツールは、動画を代わりに見て、区切りの良さそうな場所を自分で見つけてチャプターを打ちます。出力は、プレイヤーと Stash（こういう動画の管理に特化したライブラリアプリ）が読めるチャプターファイルです。あとはプレイヤーにチャプターの一覧が出るので、クリックすればその場面へ直接飛べます。もうシークバーで博打を打つ必要はありません。

区切りは2か所を見て判断します。

1. **画面が場面転換する場所。** 直前とはまったく違う内容へパッと切り替わる場所——いわゆるハードカットですが、要は「画面がガラッと変わる」ところです。そこが大抵、一段落の終わりです。どんな動画でもこの方法で探せます。
2. **付属の funscript が長く静かになる場所。** 動画によっては、同名の `.funscript` ファイルが付いてきます。これは、パソコンから遠隔操作できる電動オナホールへの「動作の指示書」のようなもので、動画の再生に合わせて機器が動きます。その指示書の中で、ほぼ動きのない状態が長く続く区間（デフォルト45秒以上）があれば、そこで展開が一休みしている証拠なので、区切りとして数えます。カメラだけでは分からない段落の切れ目を拾うためのものです。

## 何をするものか

2つをマージして、`--min-length` より短いチャプターは前のチャプターへ畳み込みます。最初のチャプターは必ず 0 秒から。

出力は3つ：

- `<name>.ffmeta` — プレイヤー用のチャプターファイル（FFMETADATA 形式）。mkv/mp4 の中へそのまま入れられます
- `<name>.chapters.json` — チャプターごとの名前（`title`）と開始時刻（`start_time`）だけのシンプルな一覧。Stash のようなライブラリ系ツールが取り込む形です
- コンソールへの一覧表示。各行に `[scene]` か `[gap]` のタグが付くので、区切りの出どころが分かります

`--embed` を付けると `<name>_chapters.mkv` も作ります。チャプター埋め込み済みで、映像と音声はそのままコピーするだけ（再エンコードなし）、元のファイルには一切触りません。

## インストール

Python 3.10+ と、PATH の通った `ffmpeg` / `ffprobe`。それだけです。スクリプトは標準ライブラリのみで、pip で入れるものはありません（`requirements.txt` は、まさにそのことを書くために置いてあります）。

## 使い方

```bash
# 基本：シーンチェンジだけ
python chapters.py movie.mp4

# 同名の movie.funscript があれば自動で使います。
# 明示もできます
python chapters.py movie.mp4 --script movie.funscript

# 検出を敏感にして、最短チャプター30秒、
# ついでに新しい mkv へ埋め込む
python chapters.py movie.mp4 --scene-threshold 0.3 --min-length 30 --embed
```

出力はこんな感じです：

```
movie.mp4: 4 chapters (2 scene cuts, 1 gap breaks)
   1. 00:00:00  Chapter 1  [start]
   2. 00:00:20  Chapter 2  [gap]
   3. 00:00:30  Chapter 3  [scene]
   4. 00:01:00  Chapter 4  [scene]
```

## パラメータ

| フラグ | デフォルト | 役割 |
|---|---|---|
| `--script` | 同名 `.funscript`（あれば） | 空白検出に使う funscript |
| `--scene-threshold` | `0.4` | カットと判定するシーン score のしきい値。低いほど敏感 |
| `--min-length` | `60` | チャプターの最短の長さ（秒）。これより短いものは前に合体 |
| `--gap` | `45` | スクリプトの低活動が何秒続いたら区切りとするか |
| `-o`, `--out-prefix` | 動画パスから拡張子を除いたもの | `.ffmeta` / `.chapters.json` の出力先 |
| `--embed` | オフ | チャプター埋め込み済みの `<name>_chapters.mkv` も出す |

## 正直な制限

- **フェードやディゾルブは検出できません。** シーン検出は急激な変化を見るものなので、ゆっくりしたクロスフェードはしきい値の下をすり抜けます。実質、ハードカット専用です。
- **しきい値は動画ごとに調整が要ります。** 派手なモンタージュは 0.4 で切りまくり、固定カメラのトーク動画では一度も引っかからないことも。実行して、一覧を見て、直して、もう一度——速いので苦にはなりません。
- **gap モードはスクリプトの質しだい。** もともと疎で自然な間が多いスクリプトは区切りを捏造しますし、最初から最後まで dense なスクリプトからは空白は取れません。出力の `[gap]` タグは、自分で判断してもらうために付けています。
- チャプター名は `Chapter N` だけです。名前を付けるのはあなたの仕事——このツールは継ぎ目を探すだけで、内容を理解するわけではありません。

## テスト

`tests/run_tests.py` は、見た目がまったく違う3つの区間をハードカットで繋いだ90秒の合成動画（切断点は正確に30秒と60秒）と、20秒から55秒間の完全な空白を持つ funscript を生成し、埋め込んだチャプターを ffprobe で読み戻すところまで含めて全工程を検証します。私の環境では検出されたチャプターは 0 / 20 / 30 / 60 秒で、ぴったりでした。テストに実素材は一切使っていません。
